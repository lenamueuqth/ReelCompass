# ReelCompass

ReelCompass enables real-time navigation and data synchronization via GPS tracking, utilizing a decentralized system manager.

ReelCompass is aimed at developers who need a straightforward, dependable solution.

- rust

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ReelCompass.git`
2. `cd ReelCompass`
3. Install in editable mode: `pip install -e .`

## Configuration

ReelCompass is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
